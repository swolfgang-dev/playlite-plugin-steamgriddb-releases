# SteamGridDB for Playlite

Install through **Playlite → Settings → Plugins → Available** and restart Playlite. Enter a SteamGridDB API key under **Settings → Plugins → Metadata → SteamGridDB**.

Provides basic game names and links, plus community covers, hero images, icons, and logos. Search by game name, SteamGridDB ID/URL, Steam store URL, or `steam:APP_ID`.

[Get an API key](https://www.steamgriddb.com/profile/preferences/api) · [SteamGridDB API documentation](https://www.steamgriddb.com/api/v2)

This repository distributes standalone plugin packages and metadata. Development takes place separately.
